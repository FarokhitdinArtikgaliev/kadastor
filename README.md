# Кадастр Маршрут v25

- 5 вкладок: Главная, Филиалы, Отчёты, Финансы, Настройки.
- Пробег рассчитывается по дорожному маршруту; GPS-разрешение не используется.
- До 4 выбранных филиалов в маршруте.
- Google Maps открывается через нативный Capacitor bridge и получает origin/destination/waypoints.
- В карточке филиала номера телефонов отображаются как обычный текст, без кнопок звонка.
- GitHub Actions после `npx cap add android` устанавливает нативный Maps bridge и собирает debug APK.

## v25 — отчёт по километражу и фото Яндекс Навигатора
- В отчётах каждая поездка показывает общий расчётный дорожный километраж, дату/время, маршрут, посещённые филиалы и расчётную компенсацию.
- Для каждого посещённого филиала сохраняется время отметки; если маршрут уже был рассчитан, также сохраняется накопленный километраж до филиала.
- При завершении поездки можно прикрепить скриншот Яндекс Навигатора с фактическим километражом.
- Фото можно добавить позже прямо в разделе «Отчёты».
- Кнопка «Поделиться» формирует текстовый отчёт и, если Android поддерживает Web Share файлов, прикладывает скриншот Яндекс Навигатора.
- GPS по-прежнему не используется.
