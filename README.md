# Кадастр Маршрут — новая версия

Приложение перестроено с нуля вокруг рабочего сценария:

1. **Главная** — пробег по GPS, заправки, компенсация, чистый результат и кнопка «Начать работу».
2. **Филиалы** — 47 объектов, контакты, ответственный, руководитель, телефоны, координаты и статус посещения.
3. **Отчёты** — журнал посещений с датой/временем и история GPS-поездок.
4. **Финансы** — фактические заправки, прочие расходы и расчёт результата.
5. **Настройки** — компенсация за км, расход автомобиля, цена топлива, тип топлива и правило автоматического учёта посещения.

Маршруты: Дом или любой филиал → до 4 филиалов → Дом. Для предложений используется дорожный расчёт OSRM с резервным ориентировочным расчётом при отсутствии сети. Кнопка «Навигация» открывает Google Maps.

GPS включается при старте навигации и считает фактический пробег. На Android должны быть разрешения `ACCESS_FINE_LOCATION` и `ACCESS_COARSE_LOCATION`.
