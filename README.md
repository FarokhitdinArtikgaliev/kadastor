# Кадастр Маршрут v30

Добавлено формирование Excel-отчёта `Safar ma'lumotlari` за произвольный период. Отчёт повторяет структуру маршрутного шаблона: начальная и конечная точки, область, адрес, координаты, время и расстояние. Для поездок без данных по отдельным участкам общий пробег и длительность распределяются по точкам маршрута расчётно.

Добавлено ручное добавление посещений из раздела «Отчёты»:
- откуда ехал: Дом или любой филиал;
- куда: филиал;
- дата и время посещения;
- статус;
- что делал / результат;
- дорожный километраж между точками автоматически рассчитывается и добавляется в общий пробег, компенсацию и финансовую статистику.

Сохранены функции v28: поиск, ближайшие филиалы, возврат домой, Google Maps / Яндекс.Навигатор, посещения, отчёты и резервная копия.
